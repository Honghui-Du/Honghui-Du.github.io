This repository provides the open-source implementation of **JAX-MPM**, a learning-augmented differentiable meshfree framework for GPU-accelerated Lagrangian simulation and geophysical inverse modeling. It integrates the **Material Point Method (MPM)** with neural networks via **JAX**'s differentiable programming and JIT compilation, enabling physics-based simulations of fluids, granular materials, and deformable bodies with support for inverse parameter identification. This code accompanies the paper published in *Engineering with Computers* (2026).
